# Doro Motion 1.1.0 (local build) terms

The original Doro artwork keeps the terms in DORO-ARTWORK-TERMS.md.

The base, working, thinking, reading, success and popcorn frames are derived from the official NIKKE LINE sticker package 37304940 (NIKKE Official Sticker, 8th Batch) and from drawings generated from them; the spider movement joins the emoji.gg Doro spider tiles. Original artists and redistribution permission are not verified.

This build is for personal use on this machine only. Do not publish, redistribute or add it to a gallery.

Version 1.1.3 additionally derives nap artwork from official NIKKE LINE package 32367107 (7th Batch), with locally generated connectors. Existing local personal-use restrictions remain.
