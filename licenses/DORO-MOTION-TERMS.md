These images were uploaded by Menyou on emoji.gg. Uploader credit is not an
assertion of authorship. Original artists and full redistribution permissions
have not been independently verified. The code repository's Apache-2.0 licence
does not apply to this artwork. This local package grants no additional rights.

The sample page https://emoji.gg/emoji/25686-doro displayed Basic License on
2026-10-28, allowing use on Discord, Slack and platforms where users are not
charged for access to the emoji. Only this sample page's terms were captured;
this is not confirmation of the terms for the remaining artworks. Review the
original creators' terms before redistribution or publication.

# Doro Motion 1.1.2 — local approval artwork

Includes the accepted v3 ping/pleading entry and exit drawings and a four-second pleading-eye loop. This is a full pet archive, with the same doro-motion identity. All earlier artwork is preserved.

The package adds artwork without native scheduler changes.

- Urgent attention still cuts the outgoing work exit; its new start begins at the shared base.
- Native approval resolution may redraw the working variant; same-variant resume was preview control logic.
- Resolution leaves an approval loop immediately, including during a blink; it does not wait for the eye loop.
- Normal resolution during entry completes the 455 ms entrance before exiting; newer urgent cues still cut immediately.
- Existing success, mood/bedtime art, tool/session timing and all other routing are unchanged.

LINE-derived and mixed-source artwork stays local for personal use; do not publish to a gallery.
